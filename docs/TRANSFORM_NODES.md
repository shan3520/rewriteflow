# Transformation Nodes Reference

## Available Nodes

- `GrammarFixNode`: Fixes spacing, punctuation, double words, capitalization.
- `ToneShiftNode`: `{"target_tone": "formal" | "casual"}`
- `ParaphraseNode`: Replaces key terms with synonymous phrasing.
- `SummarizeNode`: `{"max_sentences": int}`
- `SimplifierNode`: Replaces complex vocabulary with plain language.
- `VocabularyEnhancerNode`: Elevates everyday adjectives.
- `SEOOptimizerNode`: `{"keywords": list}`
- `StyleTransferNode`: `{"persona": "hemingway" | "corporate" | "academic"}`
